# Arduino Blink Test

Mon tout premier projet Arduino téléversé et suivi via Git & GitHub !

##  Description
Ce projet consiste à faire clignoter une LED branchée sur la broche numérique 13 d'une carte Arduino.

##  Matériel Utilisé
- 1 x Carte Arduino Uno
- 1 x LED rouge
- 1 x Résistance 220 Ω
- 1 x Breadboard & Câbles Dupont

##  Schéma de Câblage
- **LED Anode (+)** ➔ Broche Digital 13
- **LED Cathode (-)** ➔ Résistance 220 Ω ➔ Broche GND
